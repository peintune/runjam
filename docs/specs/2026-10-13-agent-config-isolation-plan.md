# Codex 配置隔离实施计划

目标：实现设计稿的 Codex 第一阶段，支持本机原生登录与会话独立托管配置切换。

1. 增加经过验证的启动方案解析器，测试原生路径、模式约束、模板不变和托管会话隔离。
2. 代理增加运行实例路由，绑定确切模型快照、局部凭据及会话推理参数。
3. Codex 启动采用解析结果；握手失败不替换原客户端，停用旧进程事件。
4. 模型管理的 Codex 操作只更改 DB/托管模板；切原生保留模型绑定，实时读取本机配置。
5. 主窗口与宠物共用原生选项和启动参数，提供上下文交接选择、运行来源信息与默认模式切换。
6. 核验单元测试、TypeScript、前端构建和 Rust 编译；记录尚需真实账号验证的认证与适配器能力。

风险：ACP 适配器与系统 CLI 版本不一定相同；不承诺未验证的原生 resume 或完整内存恢复。
替代方案：完全独立订阅登录另行接入，当前原生模式优先沿用本机 CLI 登录。
